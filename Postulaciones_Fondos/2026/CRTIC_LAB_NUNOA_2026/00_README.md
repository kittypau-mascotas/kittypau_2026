## Por qué existe esta carpeta separada

Sigue la regla del sistema de trabajo (`../00_SISTEMA_TRABAJO.md`): la narrativa madre
vive en `../documento_2026/`, acá solo van las **diferencias reales** para este fondo
específico — que en este caso son grandes, porque CRTIC no evalúa con el mismo lenguaje
que CORFO/ANID (ver `01_NARRATIVA_TECNOCREATIVA_CRTIC.md`).
