# Archivado — Documentos Legacy

> Documentos obsoletos, supersedidos o de referencia histórica.
> No se actualizan — solo se consultan para contexto histórico.
> Un documento activo nunca debe depender de un documento archivado.

---

## Criterio de archivado

Un documento se archiva cuando:
- Fue reemplazado por una versión más nueva en una carpeta activa
- Corresponde a un ciclo de experimento cerrado (Alpha v1, etc.)
- Era un borrador que nunca llegó a producción
- La funcionalidad que describe fue eliminada del proyecto

## Cómo archivar un documento

1. Mover el archivo a esta carpeta `99_Archivado/`
2. Cambiar frontmatter: `status: archived`
3. Agregar nota al inicio del doc: `> ⚠️ ARCHIVADO — [fecha] — reemplazado por [[link]]`
4. Agregar fila a la tabla de este índice
5. Actualizar el doc que lo reemplaza para que ya no linkeé al archivado
