# Reuniones — Actas y Decisiones

> Actas de reuniones del equipo Kittypau.
> Para decisiones técnicas formales, usar ADRs en [[23_Decisiones/MOC_ADR]].
> Crear actas usando `_Templates/TPL_MEETING.md`.

---

## Convención de nombres

```
MEET_YYYYMMDD_[tema].md
```

Ejemplo: `MEET_20260628_KickoffAlphaV2.md`

---

|---|---|---|---|
| (por agregar) | | | |

---

## Cómo crear un acta

1. Copiar `_Templates/TPL_MEETING.md`
2. Nombre: `MEET_YYYYMMDD_Tema.md`
3. Llenar: participantes, agenda, decisiones, accionables
4. Agregar fila a la tabla de este índice
5. Si hay una decisión técnica importante → crear también un [[23_Decisiones/MOC_ADR|ADR]]
